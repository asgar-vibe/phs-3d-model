# โมเดล 3D Interactive โรงเรียนมัธยมปัญญารัตน์ (Panyarat High School 3D)

โปรเจกต์เว็บแอปพลิเคชัน 3D Interactive จำลองผังแม่บทของ **โรงเรียนมัธยมปัญญารัตน์ (PHS)** ซอยสีลม 18 กรุงเทพมหานคร พัฒนาด้วย **Three.js + Vite** รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ (Responsive & Touch-Friendly) 

---

## 🏛️ สรุปผังแม่บทอ้างอิงภาพอัปเดตล่าสุด (`/idea/plan1.png`)

1. **กลุ่มอาคารเรียน 4 ปีกเชื่อมกันเป็นสี่เหลี่ยมสมบูรณ์ (Courtyard Quad):**
   - **ความสูงเท่ากันหมด:** 5 ชั้น (ความสูง 18.0 เมตรเท่ากันทั้ง 4 ปีก)
   - **อาคารทิศเหนือ:** กว้าง 41 ม. × ลึก 11 ม. (โดย **ชั้น G เป็นโรงอาหาร Canteen** ตามผัง)
   - **อาคารทิศตะวันออก:** กว้าง 11 ม. × ลึก 49 ม. เลียบขนานซอยสีลม 18 พร้อม **ทางเข้าหลัก (Entrance)**
   - **อาคารทิศใต้:** กว้าง 41 ม. × ลึก 11 ม. เชื่อมปีกตะวันออกและตะวันตก
   - **อาคารทิศตะวันตก:** กว้าง 11 ม. × ลึก 49 ม. เชื่อมเหนือ-ใต้ หันหน้าเข้าหาโรงยิม
2. **พื้นที่คอร์ทกลางแจ้งภายในอาคารสี่เหลี่ยม:**
   - **ทางเดินมีหลังคา (Covered Walkway):** ทางเดินคลุมสะพานข้ามคอร์ทเชื่อมระหว่างปีกตะวันตกและปีกตะวันออก (ไม่มีตึกคั่น)
   - **ลานเสาธง & สวนหย่อม (เสาธง):** อยู่คอร์ทฝั่งทิศเหนือ
   - **ลานจอดรถ (parking):** อยู่คอร์ทฝั่งทิศใต้ พร้อมเกาะหยักสีเขียว (Zig-zag)
   - **ทางเข้าหลัก (Entrance):** อยู่ริมซอยสีลม 18 ตามลูกศรสีแดง ชี้ตรงเข้าสู่ลานจอดรถและคอร์ทกลาง
3. **อาคารปีกทิศตะวันตกสุด (West Side across Driveway):**
   - **โซนโรงอาหารทิศตะวันตก (Canteen Corner):** มุมทิศตะวันตกเฉียงเหนือ
   - **โรงยิมเนเซียม (Gym):** อาคารโถงสูง หลังคาทรงโค้ง ภายในเป็น **สนามบาสเกตบอลในร่มขนาดมาตรฐาน (28 × 15 ม.)**
   - **หอประชุม (Auditorium):** อาคารหอประชุมสำหรับจัดพิธีการและการแสดงด้านทิศใต้

---

## 🚀 วิธีการเปิดใช้งานโปรเจกต์

1. เริ่มต้น Development Server:
   ```bash
   npm run dev
   ```
2. เปิดเบราว์เซอร์:
   - **บนคอมพิวเตอร์:** เปิด `http://localhost:3000/`
   - **บนมือถือ (ในเครือข่าย WiFi เดียวกัน):** เปิดตาม IP เช่น `http://192.168.1.103:3000/`
